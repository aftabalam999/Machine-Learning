# Machine Learning Projects

This repository contains a collection of machine learning projects and notebooks covering data analysis, preprocessing, model building, and predictive analytics.

## Overview

The projects in this repository include:

- Heart Disease Prediction
- Insurance Cost Prediction
- House Rent Prediction
- Spam Detection

Each project demonstrates a practical workflow involving:

- Data cleaning and exploration
- Feature engineering
- Model training and evaluation
- Visualization of results
- Application development for simple prediction systems

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Flask (for spam detection app)

## Getting Started

1. Clone the repository.
2. Open the relevant notebook in Jupyter.
3. Install the required dependencies:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn flask
```

4. Run the project files or notebooks as needed.
